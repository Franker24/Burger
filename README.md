# Brasa Burger

Sitio web de Brasa Burger, una hamburguesería de Buenos Aires especializada en hamburguesas smash. La web permite conocer la propuesta del local, recorrer la carta y armar un pedido para delivery o take away.

## Qué ofrece

- Página de inicio con productos destacados, promociones e información del local.
- Carta organizada por categorías: hamburguesas clásicas y smash, pollo, opciones vegetarianas, acompañamientos, bebidas y postres.
- Detalle de productos con descripción, imagen y precio.
- Carrito para agregar productos y revisar el pedido.
- Opciones para continuar con un pedido de delivery o take away.
- Información de contacto y medios de pago.

## Requisitos

- Node.js
- pnpm

## Desarrollo local

1. Instalar las dependencias:

   ```bash
   pnpm install
   ```

2. Iniciar el servidor de desarrollo:

   ```bash
   pnpm dev
   ```

3. Abrir [http://localhost:3000](http://localhost:3000).

## Comandos disponibles

- `pnpm dev`: inicia el servidor local.
- `pnpm build`: genera la versión de producción en `dist`.
- `pnpm preview`: sirve localmente la versión generada.
- `pnpm lint`: verifica los tipos de TypeScript.
